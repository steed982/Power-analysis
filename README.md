# 电池摄像头功耗计算器（项目版）

一个面向研发/FAE 的本地网页工具，用于计算电池摄像头在不同模式下的功耗与续航，并按项目保存参数配置。

## 功能特性

- 项目管理：新建、保存、另存为、删除、下拉选择
- 功耗模式：休眠唤醒 / AOR / 长电 / 智能
- 平台规则：
  - `OV8000` 仅支持 `休眠唤醒`、`长电`
  - 其他平台支持全部 4 种模式
- 无线类型规则：
  - `Wi-Fi` 自动设置休眠功耗为 `2mW`
  - `4G` 自动设置休眠功耗为 `6mW`
- 实时计算结果：续航、平均功耗、每日能耗、活动时长
- 图表展示：每日能耗构成（活动/休眠/AOR）
- 导出：CSV、打印/PDF
- 本地存储：`localStorage` 保存项目数据

## 文件结构

- `index.html`：页面结构
- `styles.css`：样式与响应式布局
- `app.js`：状态管理、规则约束、计算逻辑、导出
- `LPGE/index.html`：参考页面（旧版单页）

## 项目参数说明

- `项目名称`：用于保存/选择项目
- `电池电量 (mAh)`：电池容量
- `无线类型`：影响休眠功耗自动赋值（Wi-Fi/4G）
- `硬件平台`：影响可选模式（OV8000 限制模式）

## 计算参数说明

- `工作电压 (V)`
- `放电效率 (%)`
- `Active 功耗 (mW)`
- `唤醒次数 / 天`
- `单次录制时长 (秒)`
- `AOR 功耗 (mW)`（仅 AOR/智能模式相关）
- `智能切换阈值 (%)`（仅智能模式）

## 数据存储

- 当前版本存储键：`power-analy-mvp-projects-v2`
- 兼容迁移旧版本：`power-analy-mvp-scenarios-v1`（首次打开时自动尝试迁移）

## 注意事项

- `休眠功耗` 为只读，由无线类型自动设定
- 若切换到 `OV8000` 且当前模式不受支持，会自动切到 `休眠唤醒`
- 活动时长超过 24 小时/天会触发校验错误
